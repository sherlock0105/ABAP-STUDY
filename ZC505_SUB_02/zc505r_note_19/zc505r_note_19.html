*목표 : 특정 인터널 테이블에 있는 레코드를 다른 인터널 테이블에 옮기기 .

DATA : lv_num TYPE i,

       BEGIN OF ls_scarr,
         carrid   TYPE scarr-carrid,
         carrname TYPE scarr-carrname,
         url      TYPE scarr-url,
       END OF ls_scarr,

       BEGIN OF ls_spfli,
         carrid   TYPE spfli-carrid,
         connid   TYPE spfli-connid,
         airpfrom TYPE spfli-airpfrom,
         cityfrom TYPE spfli-cityfrom,
         url      TYPE scarr-url,
         carrname TYPE scarr-carrname,
       END OF ls_spfli,

       BEGIN OF ls_sflight,
         carrid   TYPE sflight-carrid,
         connid   TYPE sflight-connid,
         fldate   TYPE sflight-fldate,
         carrname TYPE scarr-carrname,
         airpfrom TYPE spfli-airpfrom,
         url      TYPE scarr-url,
       END OF ls_sflight,

       lt_spfli   LIKE TABLE OF ls_spfli,
       lt_scarr   LIKE TABLE OF ls_scarr,
       lt_sflight LIKE TABLE OF ls_sflight.

CLEAR   : ls_scarr, ls_spfli, lv_num.
REFRESH : lt_spfli, lt_scarr.

lv_num = 1.
ls_scarr-carrid   = 'AA'.
ls_scarr-carrname = 'American'.
ls_scarr-url      = 'www.aa.com'.

ls_spfli-carrid   = ls_scarr-carrid.
ls_spfli-url      = ls_scarr-url.
ls_spfli-carrname = ls_scarr-carrname.

MOVE ls_scarr-carrid    TO ls_spfli-carrid.
MOVE ls_scarr-url       TO ls_spfli-url.
MOVE ls_scarr-carrname  TO ls_spfli-carrname.

*필드가 같음, 근데 많으면 일일히 하나 하나 다 적을수 없다.
* 위의 구문을 대체하기 위해서 MOVE-CORRESPONDING 사용, 같은 필드명은 알아서 들어가라.

MOVE-CORRESPONDING ls_scarr TO ls_spfli.
