FORM display_dynamic_list .

  DATA : lt_mara    TYPE TABLE OF mara, "data 선언
         lt_marc    TYPE TABLE OF marc,
         lt_sflight TYPE TABLE OF sflight.

  FIELD-SYMBOLS : <lft_itab> TYPE ANY TABLE.

  REFRESH  : lt_mara, lt_marc, lt_sflight.
  UNASSIGN : <lft_itab>. "Clear

  CASE pa_tab.
    WHEN 'MARA'.
      ASSIGN lt_mara TO <lft_itab>.

    WHEN 'MARC'.
      ASSIGN lt_marc TO <lft_itab>.

    WHEN 'SFLIGHT'.
      ASSIGN lt_sflight TO <lft_itab>.

  ENDCASE.

  IF <lft_itab> IS NOT ASSIGNED.
    MESSAGE s000 WITH pa_tab 'Table name is wrong' DISPLAY LIKE 'E'.
    LEAVE LIST-PROCESSING.
  ENDIF.

  SELECT *
    INTO CORRESPONDING FIELDS OF TABLE <lft_itab>
    UP TO 10 ROWS
    FROM (pa_tab).

  IF sy-subrc NE 0.
    MESSAGE s001.
    LEAVE LIST-PROCESSING.
  ENDIF.

  cl_demo_output=>display( <lft_itab> ).

ENDFORM.

FORM field_control_dynamic_itab .

  DATA : lt_fagl   TYPE TABLE OF faglflext,
         ls_fagl   LIKE LINE OF lt_fagl,
         lv_field  TYPE fieldname,
         lv_mon(2) TYPE n.

  FIELD-SYMBOLS : <lfv_field> TYPE any.

*clear
  SELECT *
    INTO CORRESPONDING FIELDS OF TABLE lt_fagl
    FROM faglflext
   WHERE ryear = '2026'.

*HSL01 ~ HSL12 필드에 10,000 을 더하는 로직

  DATA : lv_name(50),
         lv_num(2) TYPE n.

  LOOP AT lt_fagl INTO ls_fagl.

    DO 12 TIMES.
      lv_mon = sy-index.

      CLEAR lv_field.
      UNASSIGN <lfv_field>.

*     ASSIGN 구문을 사용할때는 할당하고자 하는 변수(스트럭쳐,ITAB등)
*     FULL NAME 을 줘야한다.

      CONCATENATE 'LS_FAGL-HSL' lv_mon INTO lv_field.

      ASSIGN (lv_field) TO <lfv_field>. " () 를 안하면 그냥 lv_field 가 된다, 구조를 받음.
      " 값을 주고 싶을때 ()

*      ASSIGN COMPONENT : Structure 에만 사용 가능
*         CONCATENATE 'HSL' lv_mon INTO lv_field.
*         ASSIGN COMPONENT lv_field OF STRUCTURE ls_fagl TO <lfv_field>.

      IF <lfv_field> IS ASSIGNED.
        <lfv_field> = <lfv_field> + 10000.
      ENDIF.

    ENDDO.

  ENDLOOP.

** 공통사항 : ASSING 대상은 반드시 해당 FORM 또는 TOP 에 DATA 로 선언이 되어 있는 것만 가능하다.
*
*  ASSIGN lt_fagl TO <lt_itab>.    "--> lt_fagl itab 과 필드심볼 동일화
*  ASSIGN lv_matnr TO <lv_field>.  "--> lv_matnr 필드가 필드심볼과 동일화
*  ASSIGN ls_fagl TO <lfs_itab>.   "--> ls_fagl 스트럭쳐가 필드심볼과 동일화
*  ASSIGN (lv_var) TO <fs>.        "--> lv_var 변수 안의 값이 필드심볼과 동일화
** ASSIGN 구문을 사용할때는 필드심볼에 할당할 대상의 FULL NAME 이 와야한다.
*
*  ASSIGN COMPONENT <필드> OF STRUCTURE <structure> TO <fs>.
*  "--> ASSIGN COMPONET 는 스트럭쳐에만 사용 가능.

ENDFORM.
