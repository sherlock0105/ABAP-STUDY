FORM delete_data .

  _clear gs_row gt_row.                    "gs_row, gt_row clear

  CALL METHOD gcl_grid->get_selected_rows  " 어떤 행이 선택되는지 알기 위해 method 호출
    IMPORTING
      et_index_rows = gt_row.              " Indexes of Selected Rows

  IF gt_row IS INITIAL.                    "만약 사용자가 행을 선택하지 않고 delete를 눌렀을때 알려주는 안내 메세지
    MESSAGE s000 WITH 'First, select rows'.
    EXIT.                                  "exit  불필요한 로직 수행을 막는다.
  ENDIF.

  SORT gt_row BY index DESCENDING.         "ITAB 의 ROW 를 지울 때는 역순으로 삭제해야한다. DESENDING 정렬

  LOOP AT gt_row INTO gs_row.

    READ TABLE gt_mat INTO gs_mat INDEX gs_row-index.

    IF sy-subrc EQ 0.

      APPEND gs_mat TO gt_mat_del.      "삭제할 레코드를 gt_mat_del 에 옮겨준다.
      CLEAR  gs_mat.

      DELETE gt_mat INDEX gs_row-index. "gt_mat 에서 해당 레코드를 지워준다.

    ENDIF.

  ENDLOOP.

  PERFORM refresh_grid.                 "ALV는 모르는 상태 REFRESH 로 알려준다.

ENDFORM.
